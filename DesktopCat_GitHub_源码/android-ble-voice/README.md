# 桌面招财猫 Android App

这是按旧 APK 的遥控功能重新制作的独立应用，不是旧 APK 的二进制修改。0.2.0 版重新设计为“控制 / 蓝牙 / 对话”三页，保留 Wi-Fi 主板连接、实时状态、动作与表情、舵机启动和关闭、校准页面入口、语音转动作指令及操作记录；新增 BLE 控制、手机语音识别与播报、云端对话及本地记录。

用 Android Studio 打开本目录，安装 Android SDK 35，并使用 JDK 17–23。项目包含 Gradle 8.10.2 Wrapper，可运行 `./gradlew assembleDebug`。APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，是供测试安装的 debug 签名包；最低支持 Android 8.0。

先烧录 S3 固件，按仓库根目录 README 创建 `Secrets.h`。手机连接 S3 的 Wi-Fi 热点后，在“控制”页填写 `http://192.168.4.1`，连接、校准并启动舵机。此后可以继续用 Wi-Fi 控制，也可切换到“蓝牙”页，输入与固件一致的 BLE 令牌并连接，再在“控制”页选择 BLE 遥控。BLE 不支持校准和启动舵机。

“对话”页使用手机系统的语音识别和 TTS，并通过电脑上的 `voice-proxy` 访问 OpenAI。详细设置见仓库根目录的 `API配置指南.md`。OpenAI API key 只放在电脑代理进程，不写入 APK，也不在手机中输入；手机只填写局域网代理地址和代理令牌。S3 热点可能让手机离开可访问电脑的家庭 Wi-Fi，使用云端对话时建议以 BLE 控制 S3，让手机继续连接家庭 Wi-Fi。

最近 20 条对话保存在 Android 私有应用存储，并随下一次请求作为上下文发送；清空或卸载应用会删除本机记录。代理不持久化对话，Responses API 请求设置 `store:false`。BLE 令牌和代理令牌不会保存在手机中，重新打开需再次输入。云端回复本身不会直接驱动舵机：仅当用户输入完整的固定动作短句，且再次确认后，App 才会发送白名单指令。

Android 工程已完成 `assembleDebug` 编译、APK 签名和 ZIP 对齐验证，网页界面已作桌面浏览器预览；手机安装、BLE 实连、S3 Wi-Fi 接口及真实云端请求仍需用实物验证。C5 板载麦克风和扬声器尚未接入云端链路。
